# Synthetic audience panel walkthrough

This example uses a fictional Spanish-learning app. The supplied historical outputs came from the live method on 2026-11-15 with `jev-1.14.0`. They are panel answers, not measured advertising results.

The product offers ten minute lessons and a voice coach, with a first week free and then $9.99 a month. Ad A makes a guarantee claim. Ad B replaces that claim with specific travel situations and a clearer free-week action.

The exact inputs are in:

- `skills/synthetic-audience-panel/scripts/sample/ads.json`
- `skills/synthetic-audience-panel/scripts/sample/context.json`

## Run from the repository root

First run the offline checks:

```sh
P=skills/synthetic-audience-panel/scripts
python3 "$P/test_offline.py"
python3 "$P/audience_panel.py" selftest
python3 "$P/audience_panel.py" cohort --size 1000 --seed 7 --out cohort.json
```

The data owner must approve sending these texts to the vendor. Supply `TYPESAFE_API_KEY` through the process environment without printing it.

```sh
PRODUCT="$(python3 -c 'import json; print(json.load(open("skills/synthetic-audience-panel/scripts/sample/context.json"))["product"])')"
AUDIENCE="$(python3 -c 'import json; print(json.load(open("skills/synthetic-audience-panel/scripts/sample/context.json"))["audience"])')"
python3 "$P/audience_panel.py" run \
  --ads "$P/sample/ads.json" --product "$PRODUCT" --audience "$AUDIENCE" \
  --cohort cohort.json --out answers.json
python3 "$P/audience_panel.py" report --answers answers.json --mix cold \
  --out-md report.md --out-json report.json
```

Read `report.md`. The JSON also contains individual weights and achieved marginals. Re-project the same answers without another API call:

```sh
python3 "$P/audience_panel.py" report --answers answers.json --mix warm \
  --out-md report-warm.md --out-json report-warm.json
python3 "$P/audience_panel.py" report --answers answers.json --mix retargeting \
  --out-md report-retargeting.md --out-json report-retargeting.json
```

Before committing repository changes:

```sh
python3 scripts/validate.py
```

## Supplied cold-mix example

These are archived example values, not output generated by the commands above. The packaged script uses a different deterministic shuffle and adds raking. Fresh calls can differ. A fresh run of the packaged script on 2026-11-15 gave ad A 637 / 324 / 40 and ad B 691 / 370 / 86 per 1,000 (stop, tap, intent), gaps of +54, +46 and +46, verdict ahead, control check 0.15 and 0.18.

### panel answers, not delivery metrics

Per 1,000 virtual impressions:

| Ad | Stop | Tap | Intent |
|---|---:|---:|---:|
| A | 641 | 320 | 38 |
| B | 698 | 366 | 81 |
| B minus A | +57 | +46 | +43 |
| Generic contrast | 190 | 58 | 8 |

The archived verdict was B ahead. The generic contrast is historical evidence, not a third variant in the supplied sample file.

### panel answers, not delivery metrics

| Archived paired reading | Share |
|---|---:|
| Goes further with B | 80.6% |
| Goes further with A | 4.8% |
| About the same | 14.6% |

These shares belong to the supplied example. The prototype calculated person-better shares without weights. This CLI reports weighted shares explicitly, so do not expect these archived percentages to reproduce.

### panel answers, not delivery metrics

| Objection | A | B |
|---|---:|---:|
| Hard to believe | 29.5% | 5.2% |
| No reason to act now | 67.5% | 81.1% |

The hard-to-believe objection fell after the rewrite. No reason to act now remained the main objection. These shares describe sampled barrier answers, not every person.

## What to conclude

B is the stronger candidate under this panel's assumptions. Test the clearer travel-specific copy and investigate the lack of urgency.

Do not claim a predicted CTR, CVR, CPA or ROAS. The levels are generous: even people with no need show tap probability. The mix is an assumption. The 1,000 virtual people buy coverage, not accuracy.

The historical tool reported 13 requests, 0.9 seconds and $0.0085 per ad, with $0.0171 for the two-ad example. These are historical API accounting, not timing or cost guarantees for a new run. Check the new answers file's accounting instead.
